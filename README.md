# YOSSY Extensions for SW

有料テーマ SWELL（子テーマ可）専用の、非公式の拡張プラグインです。テーマの設定に加え、グループブロックやカスタムHTMLブロックも少し使いやすくします。

企業サイト（会社案内・サービス紹介・お問い合わせなど）でよく使う見た目の調整を、**追加の CSS を書かなくても** できるようにします。SWELL の代わりではなく、SWELL の機能の延長です。

このプラグインが足した項目は、名前の先頭が **`[Y]`** になっています。カスタマイズ画面やブロック編集画面で `[Y]` を探すと、このプラグインの設定だと分かります。

## こんな人向けです

- テーマに SWELL を使っている
- 主に企業サイトを WordPress で運営・更新している
- 「ここだけ幅を狭くしたい」「スマホだと画像が大きすぎるので最大幅を決めたい」「枠線のない項目＋説明の表を出したい」「スマホのメニューにも SNS を出したい」「PC のヘッダーバーにブログやお問い合わせを出したい」「Googleマップや YouTube 動画の縦横比を簡単に変えたい」などを、設定画面から済ませたい

SWELL 以外のテーマでは使えません。SWELL 本体を有効にしていても、SWELL の子テーマを使っていても、どちらでも大丈夫です。子テーマを書き換える必要はありません。

## 入れる前に確認すること

- WordPress のバージョンが 6.0 以上
- 使っているテーマが SWELL である（SWELL 本体でも、SWELL の子テーマでも可）

分からないときは、管理画面の「外観 → テーマ」で、今使っているテーマが SWELL（または SWELL の子テーマ）かを確認してください。SWELL のバージョンは、テーマの詳細に出ます。

このプラグインは、次の組み合わせで動作を確認しています。

- WordPress 7.1.1
- SWELL 2.19.0

WordPress は 6.0 以上であれば入る想定です。確認していないバージョン、とくに **SWELL のバージョンが違う場合** では、一部の項目がずれたり、出なかったりすることがあります。このプラグインは SWELL の画面やクラス名に後から足しているため、WordPress 本体より SWELL の更新の影響を受けやすいです。動作を保証するものではありません。

## 入れ方（GitHub から）

1. このページの緑色の **Code** ボタンを押す
2. **Download ZIP** を選んで、パソコンに保存する
3. WordPress の管理画面を開く
4. 左メニューの **プラグイン → 新規追加**
5. 上の **プラグインのアップロード** を押す
6. 保存した ZIP を選んで、今すぐインストール → **有効化**

うまく入らないときは、ZIP を一度解凍してみてください。中に `yossy-extensions-for-sw` というフォルダがあれば、そのフォルダをあらためて ZIP にまとめてアップロードします。（GitHub の ZIP は、フォルダ名の末尾に枝の名前が付くことがあります）

## 入れた直後はどうなる？

**ほとんど何も変わりません。** それで正常です。

使いたい項目だけ、あとからオンにします。サイトの見た目が突然崩れることは想定していません。

ひとつだけ例外があります。ページ上部のタイトル背景で、画像の加工方法を「なし」にしているとき、これまで効きにくかった**文字の読みやすさ用の色重ね**が、プラグインを有効にした時点で効くようになります。

## どこで設定する？

大きく 3 か所です。

1. **ページを書く画面**（投稿や固定ページの編集）  
   ブロックを選んだときに、右の設定パネルに `[Y]` が出ます。
2. **外観 → カスタマイズ**  
   SWELL の各項目の近くに `[Y]` が出ます。
3. **外観 → メニュー**  
   「メニューの位置」に `[Y]PCヘッダーバー` が出ます。

変更したら、カスタマイズ画面では「公開」、ページ編集では「更新」を押してください。メニューの位置は「保存」です。

## ページ編集でできること

ホームページや会社案内など、ブロックでレイアウトを組むときに使います。

### フルワイドブロックの中身の幅

SWELL の「フルワイド」は、背景を画面いっぱいにできます。そのままだと、中の文章の幅は SWELL 側の指定になります。

このプラグインを入れると、フルワイドを選んだときに **`[Y]カスタム幅`** が出ます。ここに数字（ピクセル）を入れると、**背景は全幅のまま、中の内容だけ好きな幅**にできます。

- `0` または空のまま → 今までどおり
- 例: `800` → 中の内容の最大幅が 800 ピクセル

トップページの帯セクションで、「背景は端まで、文字は少し細く」にしたいときに使います。

### グループブロックの最大幅と位置

グループ（いくつかのブロックをまとめた箱）を選ぶと、**`[Y]最大幅`** と **`[Y]揃え`** が出ます。

- 最大幅に数字を入れると、そのグループだけ幅を抑えられます
- 揃えで、左・中央・右に置けます
- `0` または空のまま → 今までどおり

「この囲みだけ狭くして中央に置きたい」というときに使います。

並び方向が「横並び（行）」や「縦積み（スタック）」、マス目の「グリッド」になっているグループには出ません。普通のグループだけが対象です。

### スマホでの画像の最大幅

画像ブロックを選ぶと、右の **スタイル** タブ → **サイズ**（幅・高さの下）に **`[Y]SPでの最大幅`** が出ます。

ここに数字（ピクセル）を入れると、**画面幅が 599px 以下のときだけ**、その画像の最大幅になります。パソコンでは、ブロックの幅・高さの指定のままです。

- 空欄または `0` → 今までどおり
- 例: `150` → スマホでは最大 150 ピクセル

顔写真など、「スマホだと横いっぱいになりすぎる」画像向けです。カバーやギャラリーではなく、画像ブロックだけが対象です。

### テーブルの線なしスタイル

テーブルブロックを選ぶと、右の **スタイル** に **`[Y]線なし`** が出ます。

アクセス案内のような「項目名＋説明」の表向けです。枠線とセル余白を消し、行のあいだだけ空けます。

- 1列目は折り返しません（項目名）
- 2列目以降は両端揃えです（説明。最終行は左揃え）
- 2列が基本ですが、3列以上でも 1列目だけ折り返しません
- スマホ（599px 以下）では、行の下余白は 2列目以降だけです。1列目の下は空けません

カスタムHTMLにクラスを書かなくても、テーブルブロックのスタイルを選ぶだけで同じ見た目になります。

### カスタムHTMLの地図・動画を画面幅に合わせる

Googleマップや YouTube の埋め込みコードを、**カスタムHTML** ブロックに貼ったときに使います。子テーマの CSS に `.my-map iframe { ... }` のように書かなくても、ブロックの設定だけで幅 100% と縦横比を指定できます。

1. カスタムHTMLブロックを選ぶ
2. 右の **設定** タブ（リストのアイコン）を開く
3. **`[Y]レスポンシブ`** の **`[Y]レスポンシブ対応`** にチェックを入れる
4. **`[Y]縦横比`** に、幅と高さを入れる（例: `16` : `9`）
5. スマホ縦持ちだけ違う比にしたいとき、**`[Y]SPは別の縦横比を使用する`** にチェックする
6. その下に出る **`[Y]SP縦横比`** を入れる（例: `4` : `3`。初期は `16` : `9`）

チェックを入れると、埋め込みの横幅が 100% になり、入力した縦横比が保たれます。初期状態はチェックなしなので、今までどおりの大きさのままです。

**`[Y]SP縦横比`** は、画面幅が **599px 以下**（SWELL のスマホ縦持ち）のときだけ使います。チェックを外すと入力欄は消え、どの幅でも共通の縦横比になります。

縦横比の欄に入れられるのは **1 以上の整数** だけです。

ブロックの中に iframe が複数ある場合は、同じ縦横比が全部にかかります。

## 外観 → メニュー でできること

管理画面左の **外観 → メニュー** を開きます。

### PC のヘッダーバーにリンクを出す

**項目名:** `[Y]PCヘッダーバー`

パソコン幅のいちばん上の細いバー（キャッチフレーズや SNS アイコンがある場所）に、任意のリンクを出せます。SNS アイコンの **左側** に並びます。

1. 左からメニューを選ぶか、新規に作る
2. 右の **メニューの位置** で **`[Y]PCヘッダーバー`** にチェックを入れる
3. **メニューを保存** する

- チェックを外すと、バーから消えます
- **パソコン幅（960 ピクセル以上）だけ** 出ます。スマホのヘッダーバーには出ません
- 1 階層だけです（下層メニューは出ません）
- SWELL の「SNSアイコンリストを表示する」がオフでも、この位置にメニューがあればバーに出ます。そのとき SWELL がバー自体を出していなければ、プラグインが同じ色の PC 用バーを作ります
- 親テーマの PHP（とくにヘッダー）を子テーマへコピーしていると、リンクが重複したり、ヘッダーの表示が崩れたりします。子テーマは `style.css` など見た目の調整にとどめてください

「ブログ」「リンク集」「お問い合わせ」など、会社サイトでよく使う短いリンク向けです。

## 外観 → カスタマイズ でできること

管理画面左の **外観 → カスタマイズ** を開きます。

### 段落ブロックを両端揃えにする

**場所:** カスタマイズ → サイト全体設定 → 基本デザイン → フォント設定

SWELL の「字間」のすぐ下です。

**項目名:** `[Y]段落ブロックを両端揃えにする`

チェックを入れると、投稿や固定ページの通常の段落ブロックが両端揃えになります。

- 初期状態はオフです
- 公開画面とブロックエディターの両方に反映します
- 段落の最終行は左揃えのままです
- 中央揃え・右揃えを個別に指定した段落は、その指定を優先します
- 個別に左揃えへ戻す場合は、段落ブロックのスタイルで「左揃え（両端揃えを解除）」を選びます
- 見出し、リスト、引用、ボタン、画像キャプションなどには適用しません

### ヘッダーの SNS アイコンの大きさ

**場所:** カスタマイズ → ヘッダー  
SWELL の「SNSアイコンリストを表示する」のすぐ下です。

**項目名:** `[Y]SNSアイコンのフォントサイズ（em）`

パソコンのヘッダーに出る SNS アイコン（と、同じ並びの検索アイコン）の大きさを変えられます。

- 初期値は `1.0`（SWELL の標準に近い大きさ）
- `1.0` 〜 `2.0` のあいだで、`0.1` 刻みです
- 数字を大きくするとアイコンが大きくなります

### スマホだけ、キャッチフレーズの細いバーを出す

**場所:** カスタマイズ → ヘッダー  
キャッチフレーズの「タイトルを表示」の近くです。

**項目名:** `[Y]SP用ヘッダーバーを表示する`  
**項目名:** `[Y]SPヘッダーバーのフォントサイズ（px）`

チェックを入れると、**スマホ画面のいちばん上**に、細いバーが出ます。中身は WordPress の **設定 → 一般** にある「キャッチフレーズ」です。サイズ項目は、チェックが入っているときだけその下に出ます。

- 初期状態はオフです
- パソコン幅（おおむね 960 ピクセル以上）では出ません
- キャッチフレーズが空だと、チェックを入れても出ません
- 下にスクロールしてヘッダーが追従しても、この帯は一緒に固定されません（先頭に戻ると再び出ます）
- フォントサイズの初期値は `12`（px）です。`9`〜`14` の整数で変えられます。小さいほど1行に収まりやすいです

「スマホでも、会社の一言をヘッダーに出したい」ときに使います。

### スマホの開閉メニューに SNS を出す

**場所:** カスタマイズ → サイト全体設定 → スマホ開閉メニュー  
このセクションのいちばん下です。

**項目名:** `[Y]SNSアイコンリストを表示する`

チェックを入れると、スマホのメニュー（≡ を押した中）の下部に、SNS アイコンが出ます。出るリンクは、SWELL に登録してある SNS と同じです。大きさは、ヘッダーの `[Y]SNSアイコンのフォントサイズ` に合わせます。

- 初期状態はオフです
- パソコンのヘッダーに SNS を出していても、スマホメニューには標準では出ないことがある、その穴埋めです

### スマホ開閉メニューのタイトルとメニューの揃え

**場所:** カスタマイズ → サイト全体設定 → スマホ開閉メニュー  
`[Y]SNSアイコンリストを表示する` の上です。

**項目名:** `[Y]タイトルの表示`  
**項目名:** `[Y]メニューを中央揃えにする`  
**項目名:** `[Y]メニュー下の下線を非表示にする`  
**項目名:** `[Y]メニュー下の下線の色`

「メインメニュー」の見せ方と、その下のリンク一覧の見た目を変えられます。

- タイトルは、左揃え / 中央揃え / 非表示。初期値は SWELL と同じ左揃えです
- メニューのチェックを入れると、リンクが中央揃えになり、先頭のアイコン（>）も消えます。初期状態はオフです
- 下線のチェックを入れると、各リンクの下線が消えます。初期状態はオフです
- 下線の色は、非表示がオフのときだけその下に出ます。未選択のときは SWELL のグレーのままです
- 非表示は見出しごと消すので、SWELL 側のタイトル文言を空にするより余白も残りません
- 下のウィジェット（予約ボタンなど）の見出しやボタンには使いません

### 固定ページのタイトル位置と文字サイズ

**場所:** カスタマイズ → サイト全体設定 → コンテンツヘッダー  
このセクションのいちばん下です。

次の 3 つが並びます。

1. `[Y]固定ページタイトルの横位置`（左揃え / 中央揃え）
2. `[Y]固定ページタイトルのフォントサイズ（PC）（em）`（パソコン）
3. `[Y]固定ページタイトルのフォントサイズ（SP）（em）`（スマホ）

会社情報・代表あいさつ・企業理念など、**固定ページ**の、ページ上部に出る大きなタイトル向けです。投稿（ブログ記事）には使いません。

SWELL 側で、固定ページのタイトル位置が **「コンテンツ上」** のときだけ、これらの項目が見えます。タイトルを本文の中に出している設定では、項目自体が隠れます。

目安の初期値は、SWELL の標準に合わせています。

- 横位置: 左揃え
- パソコンの文字サイズ: `1.5`
- スマホの文字サイズ: `1.3`

`em` は「いまの文字サイズを基準にした倍率」です。SWELL のほかの文字サイズ指定と同じ考え方です。数字を大きくすると、タイトルが大きくなります。

### タイトル背景を「なし」にしても、文字を読みやすくする

**場所:** カスタマイズ → サイト全体設定 → コンテンツヘッダー  
「画像フィルター」のすぐ下に、説明文が出ます。

**表示:** `[Y]「なし」でもオーバーレイカラーを有効化済み`

これはオン／オフのスイッチではありません。「すでに直してあります」という案内です。

SWELL では、ページ上部の背景写真に「ドット」などの加工を付けられます。加工を「なし」にすると、本来あるはずの**文字の下の色重ね（オーバーレイ）**が効きにくいことがあります。写真の上の白いタイトルが読みづらくなる、あの状態です。

このプラグインを有効にしているあいだは、「なし」を選んでいても、SWELL で設定したオーバーレイの色と濃さが効きます。チェックを入れる操作は不要です。

## よくある質問

### 入れたのにサイトが変わらない

正常です。ブロックの幅は、そのブロックで数字を入れたときだけ変わります。カスタマイズのチェック項目も、初期はオフです。

### `[Y]` が見当たらない

- カスタマイズなら、上に書いたメニューの場所を開いているか確認してください
- PC ヘッダーバーのリンクは、カスタマイズではなく **外観 → メニュー** の「メニューの位置」にあります
- 固定ページタイトルの `[Y]` は、SWELL のタイトル位置が「コンテンツ上」のときだけ出ます
- SPヘッダーバーのフォントサイズは、`[Y]SP用ヘッダーバーを表示する` にチェックが入っているときだけ出ます
- スマホ開閉メニューの `[Y]SNSアイコンリストを表示する` は、サイト全体設定 → スマホ開閉メニューのいちばん下です
- 下線の色は、`[Y]メニュー下の下線を非表示にする` がオフのときだけ出ます
- グループの最大幅は、横並び・縦積み・グリッドのグループには出ません
- 画像の `[Y]SPでの最大幅` は、画像ブロックの **スタイル** タブ → **サイズ**（幅・高さの下）です
- テーブルの `[Y]線なし` は、テーブルブロックの **スタイル** にあります

### 地図の大きさが変わらない

カスタムHTMLブロックを選んで、右の **設定** タブに **`[Y]レスポンシブ対応`** があるか確認してください。チェックがオフだと、埋め込みコードに書かれた大きさのままです。スタイル（歯車）タブではなく、設定タブにあります。

### 子テーマの `style.css` や `functions.php` は触る？

このプラグインの機能のためには触らなくて大丈夫です。サイト独自の色や余白は、子テーマの `style.css` に書いて問題ありません。

親テーマ（SWELL）の PHP を子テーマへコピーして上書きするのはやめてください。とくに `header.php` などヘッダー周りのファイルを置くと、このプラグインの PC ヘッダーバーや SP ヘッダーバーと重なり、メニューが二重に出たり、場所がずれたりします。サイトを移行するときも、その子テーマがそのまま先方へ入ります。

### PCヘッダーバーのメニューがたくさん出る

子テーマに、親テーマからコピーしたヘッダー系の PHP が無いか確認してください。あれば削除し、色や余白は `style.css` だけに戻します。キャッシュの削除だけでは、コピーしたファイルは消えません。

### プラグインを無効にするとどうなる？

このプラグインが足していた見た目は、出なくなります。SWELL 本体の設定や、すでに書いた文章は残ります。グループやフルワイドに入れた幅の数字は、データとしては残ることがありますが、プラグインが無いと効きません。

### SWELL をアップデートしたら、一部が効かなくなった

SWELL の画面の作りが変わると、このプラグインの一部がずれることがあります。「入れる前に確認すること」に書いた組み合わせ以外では確認していません。そのときはプラグインの更新を待つか、レッスン側の案内を見てください。SWELL 本体の不具合としては問い合わせないでください。

## 注意

- SWELL 公式のサポート対象ではありません
- 動作確認した WordPress / SWELL のバージョンは、「入れる前に確認すること」に書いてあります。それ以外の組み合わせでは確認していません
- 本番サイトに入れる前に、できるならテスト用のサイトで一度確認してください
- 親テーマの PHP を子テーマへコピーしてカスタマイズしないでください。このプラグインは SWELL 本体のヘッダーに後から差し込むため、コピーがあると表示が壊れます

- カスタムHTMLの `[Y]レスポンシブ対応` に、「Googleマップや YouTube の埋め込みコード向けです。」という説明を追加した

### 0.2.27

- `[Y]線なし` の 1列目が、ブロックエディターだけ折り返されていたのを直した。Gutenberg の固定幅テーブルと SWELL のセル最小幅が、`white-space: nowrap` を潰していた

### 0.2.26

- テーブルブロックのスタイルに `[Y]線なし` を追加した。枠線を消し、1列目は折り返さず、2列目以降を両端揃えにする。スマホでは行の下余白を 1列目だけ 0 にする

### 0.2.25

- 画像ブロックの `[Y]SPでの最大幅` を、スタイル「サイズ」の幅の真下（左列）に出すよう修正した

### 0.2.24

- 画像ブロックの `[Y]SPでの最大幅` を、スタイル「サイズ」の幅の下（左寄せ）に表示するよう修正した

### 0.2.23

- 画像ブロックの `[Y]SPでの最大幅` を、スタイル「サイズ」の高さの直下に表示するよう修正した

### 0.2.22

- 画像ブロックのスタイル「サイズ」に `[Y]SPでの最大幅` を追加し、599px 以下だけ画像の最大幅を px で指定できるようにした

### 0.2.21

- 段落ブロックの両端揃えを、公開画面だけでなくブロックエディターの編集キャンバスにも反映するようにした。

### 0.2.20

- 基本デザインのフォント設定に、通常の段落ブロックを両端揃えにする設定を追加した。最終行は左揃えのままにし、中央・右揃えと専用の左揃え解除スタイルを優先します。

### 0.2.19

- SP用ヘッダーバーを表示して公開した後、同じカスタマイズ画面でチェックを外してもプレビューに残る不具合を修正した。オフの設定値を整数 0 に正規化し、公開前の非表示も反映します。

### 0.2.18

- スマホ開閉メニューの SNS 表示チェックを、プレビューに即時反映するよう修正。非表示で開いた場合もオンに切り替えられます。

### 0.2.17

- 「[Y]タイトルの表示」の上に「[Y]メニュー全体の縦位置」を追加。上揃え（初期値）と中央揃えを選択できます。
- 上下中央揃えはタイトル・メニュー・下部ウィジェット全体に適用し、内容が高い場合はスクロールできます。

### 0.2.15

- スマホ開閉メニューの下線色設定が、チェックを外してもプレビュー更新後に消える不具合を修正した

### 0.2.14

- スマホ開閉メニューのカスタマイズ画面で、下の項目までスクロールできるようにした

### 0.2.13

- カスタマイズに `[Y]メニュー下の下線の色` を追加し、非表示オフのときだけ下線色を変えられるようにした

### 0.2.12

- カスタマイズに `[Y]メニュー下の下線を非表示にする` を追加し、スマホ開閉メニューのリンク下線を消せるようにした

### 0.2.11

- カスタマイズに `[Y]タイトルの表示` と `[Y]メニューを中央揃えにする` を追加し、スマホ開閉メニューの見出しとリンクの揃えを変えられるようにした

### 0.2.10

- カスタマイズに `[Y]SPヘッダーバーのフォントサイズ（px）` を追加し、表示オンのときだけサイズを変えられるようにした

### 0.2.9

- スマホで下にスクロールしたとき、SP用ヘッダーバーが追従ヘッダーに付いてこないようにした

### 0.2.8

- 外観 → メニュー に `[Y]PCヘッダーバー` を追加し、PC のヘッダーバー（SNS の左）にリンクを出せるようにした

### 0.2.7

- カスタムHTMLのレスポンシブで、599px 以下だけ別の縦横比を指定できるようにした

### 0.2.6

- フルワイドブロックで、中身の幅を数字指定できるようにした
- グループブロックで、最大幅と左・中央・右の位置を指定できるようにした
- ヘッダーの SNS アイコンの大きさを変えられるようにした
- 固定ページの上部タイトルの位置と文字サイズを変えられるようにした
- スマホ用のキャッチフレーズバーを出せるようにした
- スマホの開閉メニューに SNS アイコンを出せるようにした
- タイトル背景の加工が「なし」でも、文字用の色重ねが効くようにした
- カスタムHTML内の iframe（Googleマップ・YouTube など）を、任意の縦横比で幅100%にできるようにした
